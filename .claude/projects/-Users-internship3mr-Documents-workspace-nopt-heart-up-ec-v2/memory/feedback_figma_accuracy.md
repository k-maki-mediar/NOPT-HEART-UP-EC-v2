description: Figmaスクリーンショットを正確に読み取り、色・レイアウト・構造を勝手に解釈しないこと
type: feedback

Figmaから読み取れるスタイル情報（色コード、フォントサイズ、レイアウト構造）を忠実にコードに反映すること。自分の推測で色やレイアウトを変えない。

**Why:** Figmaのスタイル情報（text-[#00387d]等）を無視してネイビー背景+白文字のヘッダーを勝手に作り、本来のデザインと全く違うものを実装してしまった。

**How to apply:** まずFigmaから取得したスタイル値（色コード、フォントサイズ、余白、レイアウト方向）を正確にコードに反映する。その上で、最終確認としてスクリーンショットと見比べて差異がないか検証する。勝手にデザイン要素を追加・変更しない。
