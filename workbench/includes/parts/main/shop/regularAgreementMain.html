らくとく定期便ご利用規約

第1条《申し込み》

  2. お客様が「らくとく定期便」のお申し込みをした時点において、お客様は「本規約」に同意されたものとします。
  3. コンタクトレンズの「らくとく定期便」のお申込みに関して
    • （1）Eyeデータ（※注1）を登録されているご本人様に限りお申込みが可能です。
    • （2）ご登録のEyeデータ（※注1）の保管有効期限内であれば、「らくとく定期便」の申込商品の種類変更及び休止後の再開が何度でも可能です。
    • （3）お申込いただける商品は、一会員様に対して片眼につき一種類です。
  4. コンタクトレンズケア用品の「らくとく定期便」のお申込みに関して
    • （1）会員登録されているご本人様に限りお申込みが可能です。
    • （2）「らくとく定期便」の申込商品の種類変更及び休止後の再開が何度でも可能です。
    • （3）お申込いただける商品は、一会員様に対して一種類です。
第2条《商品のお届けについて》
  1. 「らくとく定期便」は、お客様からの休止、解約のお申し出がない限り、お申込みいただいた商品をご指定の住所へお届けします。
    なお、商品のお届けサイクル、1サイクルごとにお届けする商品点数は、お客様がお申込みのコースに基づくものとします。
  2. 「らくとく定期便」はお客様からの休止、解約のお申し出がない場合でも、次のいずれかに該当する場合は、お届けが出来ません。
    （コンタクトレンズの「らくとく定期便」）
    • （1）お申込みに必要なEyeデータ（※注1）の保管有効期限が切れている場合。
    • （2）お申込みに必要なEyeデータ（※注1）において何らかの理由によりコンタクトレンズの使用制限がなされた場合。

    （コンタクトレンズの「らくとく定期便」、コンタクトレンズケア用品「らくとく定期便」共通）

    • （3）ご注文いただいた商品代金のお支払が完了していないとき。
    • （4）クレジットカード支払の方で、カード会社から無効の連絡があったとき。
    • （5）コンビニ後払い（ベリトランス後払い）支払いの方で、決済代行業者から無効の連絡があったとき。
    • （6）住所不明や長期不在で連絡がつかず、受取れていない商品があるとき。
    • （7）前各号に掲げる事項のほか、本規約に反する行為で、当社事業の遂行に支障を及ぼす行為、または及ぼすおそれのある行為があったとき。
    • （8）製造元において製造中止、欠品、リコールなどの理由から当社に商品の供給がなされないとき。
    • （9）その他、当社が、何らかの理由によりサービスの提供を行うことが困難となったとき。
  3. 当社は、前項の規定により商品の配送を停止する際はメールにて配送停止のご連絡を行いますが、ご登録いただいているメールアドレスの不備、未登録の理由でメールが届かない場合や緊急の場合等でお客様への通知が行えない場合がございますので、あらかじめご了承ください。
  4. 商品のお届け先は、日本国内の住所に限るものとします。
第3条《「らくとく定期便」の休止、解約、商品の変更及び再開について》
  1. 「らくとく定期便」は商品の出荷準備前までであれば、ハートアップオンラインショップ及びハートアップグループ「らくとく定期便」取扱い店舗にてお届け予定日、お支払方法、お届け先ご住所、ご注文商品の種類変更及び休止、解約が可能です。
  2. 「らくとく定期便」を休止している場合、ハートアップオンラインショップ及びハートアップグループ「らくとく定期便」取扱い店舗にて再開のお申込みが可能です。
  3. お客様から「らくとく定期便」の休止のお申し出がない場合であっても本規約の第2条第2項第1号、2号、3号、4号、5号、6号に該当する場合は休止扱いとします。
  4. 本規約の第2条第2項第1号、3号、4号、5号に該当にする方で有効な情報の再登録が完了した場合や、遅延しているお支払が完了した場合は、「らくとく定期便」のお届けを自動的に再開いたします。
  5. 「らくとく定期便」の再開においては、ご指定がなければ最短のお日にちで、ご指定があればご指定のお届け日にて商品を配送致します。
  6. 「らくとく定期便」を休止して1年以上経過した際には、解約として取扱います。再度のお届けをご希望の場合は、あらためてお申込みください。
第4条《商品代金のお支払いについて》
  1. 「らくとく定期便」のお支払方法は、クレジットカード払い（一括払い/分割払い）、コンビニ後払い（ベリトランス後払い）、代金引換の3種類からお選びいただけます。
  2. クレジットカード払い（一括払い/分割払い）とはお届けした商品の代金をクレジットカードにてお支払いただく方法です。
    クレジットカードの分割払いをご指定の場合、分割払い手数料はお客様のご負担となります。
  3. コンビニ後払い（ベリトランス後払い）とはお届けした商品の代金を商品とは別に発送する請求書よりお支払いただく方法です。コンビニで現金でお支払いいただくか、請求書払いに対応している決済手段よりお支払いください。
  4. 代金引換とは商品のお届け時に配送業者に商品代金を一括でお支払いただく方法です。
  5. 消費税については、「らくとく定期便」の商品代金とは別にお支払いただきます。サービス利用期間中に税制改正があった場合は、税制改正後の発送分から改正税率を適用するものとします。
